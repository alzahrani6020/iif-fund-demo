# دليل إدارة المحتوى (CMS) — IIF

## ما تم إنجازه

### 1. JSON CMS — تعديل بدون كود

| الملف | الغرض | الموقع |
|-------|-------|--------|
| `data/news.json` | الأخبار والبيانات الصحفية | `press.html` |
| `data/projects.json` | مشاريع المحفظة | `portfolio.html` |
| `data/careers.json` | الوظائف المتاحة | `careers.html` |

**كيفية التعديل:**
1. افتح ملف JSON في أي محرر نصوص
2. أضف/عدل/احذف عناصر من المصفوفة `items`
3. احفظ → ادفع إلى GitHub → يُنشر تلقائياً

### 2. نماذج تعمل (Formspree)

| النموذج | الصفحة | الحالة |
|---------|--------|--------|
| التواصل | `contact.html` | ✅ جاهز (يتطلب YOUR_FORM_ID) |
| طلب عضوية | `apply.html` | ✅ جاهز (يتطلب YOUR_FORM_ID) |

**خطوات التفعيل:**
1. ادخل https://formspree.io/register
2. سجّل بحسابك
3. أنشئ نموذج جديد → احصل على `YOUR_FORM_ID`
4. استبدل `YOUR_FORM_ID` في:
   - `contact.html` السطر 48
   - `apply.html` السطر 50

### 3. ما يُلغى (لم يعد ضرورياً)

- ❌ Google Sheets للبيانات — استبدل بـ JSON
- ❌ MongoDB — لا حاجة لقاعدة بيانات
- ❌ Firebase — Cloudflare يكفي
- ❌ v0 by Vercel — الموقع موجود

## للمستخدم النهائي (غير مبرمج)

**لإضافة خبر جديد:**
```
1. افتح data/news.json
2. انسخ قالب الخبر وألصقه
3. غيّر: التاريخ، العنوان، النص
4. احفظ → git push
```

**لإضافة مشروع جديد:**
```
1. افتح data/projects.json
2. أضف مشروعاً للمصفوفة
3. احفظ → git push
```

**لإضافة وظيفة جديدة:**
```
1. افتح data/careers.json
2. أضف وظيفة للمصفوفة
3. احفظ → git push
```
