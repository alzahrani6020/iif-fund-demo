# منصة محمد عيضة الزهراني الثقافية

منصة ثقافية متكاملة مخصصة للشاعر السعودي محمد عيضة الزهراني، تضم ديوانه الشعري الكامل، معجم الهجة الزهرانية، مكتبة صوتية وفيديو، بالإضافة إلى الأحداث والاقتباسات.

## 🌟 المميزات

### � الديوان الشعري
- مجموعة قصائد كاملة مصنفة حسب الموضوع والزمن
- نظام بحث متقدم داخل القصائد
- إمكانية الاستماع للقصائد المسجلة
- مشاركة القصائد على وسائل التواصل الاجتماعي
- عرض تفصيلي لكل قصيدة في نافذة منبثقة

### 📖 معجم الهجة الزهرانية
- قائمة شاملة لكلمات الهجة الزهرانية
- شرح مفصل لمعاني الكلمات
- نطق صوتي للكلمات
- نظام بحث سريع في المعجم
- تصنيف الكلمات حسب النوع (اسم، فعل، صفة)

### 🎥 مكتبة الفيديو
- تسجيلات شعرية ومقابلات
- فيديوهات الأمسيات الشعرية
- تصنيف الفيديوهات حسب النوع
- مشغل فيديو مدمج
- معلومات تفصيلية عن كل فيديو

### 📞 قسم الاتصال
- نموذج اتصال متكامل
- معلومات التواصل المباشر
- تصميم سهل الاستخدام

## 🎨 التصميم والمميزات التقنية

### التصميم
- تصميم عربي أصيل باتجاه RTL
- ألوان دافئة وهادئة مناسبة للشعر
- خطوط عربية واضحة وجميلة (Tajawal)
- واجهة مستخدم حديثة وسلسة

### التقنيات المستخدمة
- **HTML5** دلالي وحديث
- **CSS3** مع متغيرات CSS للسهولة في التخصيص
- **JavaScript** حديث (ES6+)
- **Responsive Design** متجاوب مع جميع الأجهزة
- **Animations** حركات سلسة وجذابة

### المميزات التفاعلية
- قائمة تنقل متجاوبة للجوال
- تأثيرات التمرير والظهور التدريجي
- أزرار التفاعل (إعجاب، مشاركة)
- نظام إشعارات أنيق
- تأثير الكتابة الآلية للعنوان الرئيسي

## 🚀 كيفية الاستخدام

### 1. التشغيل المحلي
```bash
# ببساطة افتح الملف في المتصفح
# أو استخدم خادم محلي
python -m http.server 8000
# ثم افتح http://localhost:8000
```

### 2. التخصيص

#### تغيير معلومات الشاعر
في ملف `index.html`:
- غيّر اسم الشاعر في قسم "نبذة عني"
- عدّل معلومات الاتصال
- أضف صورة شخصية حقيقية

#### إضافة قصائد جديدة
في قسم القصائد المكتوبة، انسخ وألصق كرت القصيدة:
```html
<article class="poem-card">
    <div class="poem-header">
        <h3 class="poem-title">عنوان القصيدة الجديدة</h3>
        <span class="poem-date">التاريخ</span>
    </div>
    <div class="poem-content">
        <p class="poem-excerpt">
            محتوى القصيدة هنا...
        </p>
    </div>
    <div class="poem-footer">
        <button class="btn-read-more">اقرأ المزيد</button>
        <div class="poem-actions">
            <button class="btn-like"><i class="fas fa-heart"></i></button>
            <button class="btn-share"><i class="fas fa-share"></i></button>
        </div>
    </div>
</article>
```

#### إضافة فيديوهات جديدة
في قسم الفيديوهات، انسخ وألصق كرت الفيديو:
```html
<div class="video-card">
    <div class="video-thumbnail">
        <div class="play-button">
            <i class="fas fa-play"></i>
        </div>
        <img src="رابط-الصورة-المصغرة" alt="عنوان الفيديو">
    </div>
    <div class="video-info">
        <h3 class="video-title">عنوان الفيديو</h3>
        <p class="video-description">وصف الفيديو</p>
        <div class="video-meta">
            <span class="video-duration">المدة</span>
            <span class="video-views">المشاهدات</span>
        </div>
    </div>
</div>
```

### 3. التخصيص المتقدم

#### تغيير الألوان
في ملف `styles.css`، عدّل متغيرات CSS:
```css
:root {
    --primary-color: #8B4513;    /* اللون الأساسي */
    --secondary-color: #D2691E;   /* اللون الثانوي */
    --accent-color: #FFD700;      /* لون التمييز */
    /* ... */
}
```

#### إضافة روابط التواصل الاجتماعي
في الفوتر، عدّل الروابط:
```html
<a href="رابط-الفيسبوك" class="social-link"><i class="fab fa-facebook"></i></a>
<a href="رابط-تويتر" class="social-link"><i class="fab fa-twitter"></i></a>
<a href="رابط-انستغرام" class="social-link"><i class="fab fa-instagram"></i></a>
<a href="رابط-يوتيوب" class="social-link"><i class="fab fa-youtube"></i></a>
```

## 🌐 النشر

### على GitHub Pages
1. ارفع الملفات إلى مستودع GitHub
2. من Settings → Pages، اختر GitHub Actions
3. الموقع سينشر تلقائياً

### على GitHub Pages
1. ارفع مجلد `poet-website` إلى مستودع GitHub.
2. فعّل GitHub Pages مع مصدر GitHub Actions أو فرع `gh-pages`.
3. يمكنك ربط نطاق خاص لاحقاً من إعدادات Pages.

### على Vercel
1. استخدم Vercel CLI أو الواجهة الويب
2. اختر المجلد الرئيسي
3. انشر بنقرة واحدة
